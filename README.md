# 生死局（Sheng Si Ju）

一款 2D 卡牌对弈游戏（Godot 4.7 / GDScript），暗黑民俗志怪题材的像素风格。

> 绳、石、刀、枪、生、死 —— 六种牌的对弈。

## 下载试玩

[**下载最新构建（Release）**](https://github.com/tianyi667/sheng-si-ju/releases/latest)

把 `sheng-si-ju-v0.2.exe` 和 `sheng-si-ju-v0.2.pck` 下载到**同一个文件夹**，双击 exe 即可运行（无需安装 Godot）。


## 玩法

- 每回合从手牌中**拖一张牌到屏幕中央的释放平面**，牌会悬在角色头顶
- 敌方在回合开始时就已经暗中选好一张牌，头顶显示为**盖牌**
- 点「窥见」可以提前翻开敌方的盖牌（每回合一次机会，可累计）
- 点「回合结束」→ 敌方牌**翻面** → 结算 → 补牌进入下一回合

| 牌 | 效果 |
|---|---|
| 绳 | 克制 石；被 刀 克制 |
| 石 | 被 刀 克制 |
| 刀 | 克制 绳、石 |
| 枪 | 与所有牌平局，但被 绳 克制 |
| 生 | 与 枪 组合时压制一切 |
| 死 | 唯一能造成生命损失的方式（3 回合倒计时，爆发扣血） |

- 双方各 3 点生命
- 拼点失败：己方 +1 窥见，牌库被塞入 1 张死牌
- 死牌倒计时归零时爆发，扣 1 点生命并销毁

## 运行

1. 安装 **Godot 4.7**（GL Compatibility 渲染）
2. 用 Godot 打开本目录下的 `project.godot`
3. 按 **F5** 运行

## 操作

| 操作 | 说明 |
|---|---|
| 拖拽手牌 | 拖入中央平面（牌会缩小）→ 松手出牌；拖出平面 → 取消回手 |
| 窥见 | 翻开敌方盖牌 |
| 回合结束 | 敌方翻面 + 结算 |
| F11 / Alt+Enter | 全屏切换 |

## 项目结构

```
scenes/
  battle_scene.tscn     战斗场景（完整节点树，可在编辑器里直接改）
  card_view.tscn        卡牌场景
scripts/
  boot.gd               启动：窗口整数倍缩放 + 全屏切换
  battle/
    battle_flow.gd      回合状态机 + 规则结算
    battle_hud.gd       HUD（生命 / 死牌倒计时 / 按钮 / 结算面板）
    card_view.gd        卡牌：拖拽 / 回弹 / 翻面 / 盖牌
    hand_controller.gd  手牌扇形排布
    played_slots.gd     敌我头顶牌槽
    release_zone.gd     中央释放平面
    screen_shake.gd     屏幕震动（只抖战斗层）
  date/
    Battleresolver.gd   纯规则判定（无 UI 依赖）
    EnemyAI.gd          敌方出牌 AI
    GameManager.gd      全局状态 / 场景切换
art/pixel/              像素素材（背景 / 角色 / 卡牌）
资源/缝合怪像素字体/      像素中文字体（OFL 开源）
```
